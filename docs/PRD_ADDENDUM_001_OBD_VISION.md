# PRD Addendum 001 – OBD-Centric Product Vision

Date: 2026-06-09

## Purpose

This addendum clarifies the strategic direction of PrioraScan following completion of Vehicle Management, Authentication, Diagnostic Sessions, and the OBD Foundation MVP.

## Vision Update

PrioraScan is not intended to be a workshop management platform.

Workshop operations, scheduling, workboards, approvals, and KPI management belong to PrioraFlow.

PrioraScan's primary purpose is:

* Vehicle communication
* OBD diagnostics
* Diagnostic data acquisition
* Diagnostic intelligence
* AI-assisted analysis
* Technician reporting

## Product Positioning

PrioraFlow:

* Workshop Operations Platform

PrioraScan:

* Intelligent Diagnostic Scanner

## Updated Feature Roadmap

Completed:

1. Vehicle Management
2. Authentication
3. Diagnostic Sessions

Planned:
4. OBD Foundation - MVP COMPLETE
5. Fault Code Intelligence
6. Live Data & Sensor Monitoring
7. AI Analysis
8. Reports
9. PrioraFlow Integration

Future:
10. Freeze Frame Data
11. Graphing & Trend Analysis
12. Service Functions & Special Tests
13. OEM Integrations
14. Coding & Programming

## Strategic Principle

OBD communication is considered a core product capability and not a future integration.

All future diagnostic intelligence capabilities originate from vehicle data acquired through OBD communication.

Live Data & Sensor Monitoring is mandatory for PrioraScan's Intelligent Diagnostic Scanner positioning, but it is explicitly deferred from Feature 004 and belongs to Feature 006.
