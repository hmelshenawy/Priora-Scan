# 1. Executive Summary

PrioraScan is an AI-powered automotive diagnostic assistant designed to help technicians, service advisors, and workshops transform diagnostic fault codes into actionable repair guidance.

The platform allows users to manually enter fault codes or upload diagnostic scan reports generated by existing scan tools such as Launch, Autel, Xentry, Bosch, Thinkcar, and others.

PrioraScan analyzes the diagnostic data, explains fault codes, suggests possible root causes, recommends next diagnostic steps, and generates professional reports that can be shared internally or with customers.

The platform can operate independently or integrate with PrioraFlow to enrich workshop workflows and job management processes.

---

# 2. Problem Statement

Modern diagnostic tools successfully identify vehicle fault codes but often fail to provide structured guidance on:

* Understanding fault code meaning
* Identifying likely root causes
* Recommending next diagnostic steps
* Standardizing workshop diagnostic processes
* Preserving technician knowledge
* Generating professional customer-facing reports

Technicians frequently rely on:

* Internet searches
* Forum discussions
* Senior technician experience
* Personal knowledge

This creates inconsistency, slows diagnosis, and increases dependence on individual expertise.

---

# 3. Product Vision

To become the diagnostic intelligence layer that sits above existing automotive scan tools.

Rather than replacing scan tools, PrioraScan enhances them by converting diagnostic information into structured knowledge, recommendations, and actionable insights.

# 7. Out of Scope (MVP)

The following features are explicitly excluded from Version 1:

* Direct OBD-II communication
* Bluetooth OBD devices
* USB OBD devices
* ECU programming
* Software updates
* Vehicle coding
* Live sensor streaming
* OEM integrations
* Dealer system integrations
* Parts ordering
* Repair labor estimation

These features may be considered in future releases.

# 14. PrioraFlow Integration Strategy

PrioraScan will remain a standalone product.

PrioraFlow integration will be optional.

Integration capabilities:

* Send diagnostic sessions
* Attach scans to job cards
* Add diagnostic history
* Trigger workflow actions
* Enrich workshop analytics

This approach allows PrioraScan to serve both independent technicians and workshops using PrioraFlow.
